# Perfume Daddy — Luxury Fragrance Boutique

Pakistan's premier luxury fragrance boutique web application. Curating prestigious scent houses including Creed, Dior, Versace, Chanel, Lattafa, Armaf, Afnan, and Rasasi.

## Project Structure

```
Perfume/
├── assets/
│   └── images/          # High-fidelity photorealistic product & editorial visual assets
├── index.html           # Main semantic HTML5 markup
├── index.css            # Luxury modern CSS design system & responsive media queries
├── app.js               # Interactive drawer overlays, keyboard shortcuts, & tab handlers
├── GEMINI.md            # Modern frontend engineering & design guidelines
└── README.md            # Repository documentation
```

## Features

- **Luxury Header & Search/Cart Drawers**: Slide-in mobile navigation drawer, auto-focusing search overlay, and slide-over cart drawer.
- **Tilted Skew Ribbon Ticker**: Seamless infinite text marquee skewed at `-2.2deg` flush with viewport edges.
- **Curated Brand Color Palette Sequence**: Obsidian Dark ➔ Marquee Purple ➔ Boutique Cream-Lavender ➔ Deep Aubergine ➔ Luxury Warm Sand ➔ Midnight Black-Violet ➔ Dark Plum-Charcoal.
- **Dynamic Crop Matrices**: Crop positioning system isolating bottles from panoramic group photos without layout shifts.
- **High-Fashion Arched Portals**: Museum-style arched visual wrappers for signature perfumes.
- **Full Mobile Responsiveness**: Fluid clamp typography and touch-optimized layout grids across 320px–1920px viewports.
